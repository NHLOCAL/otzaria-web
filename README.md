# אוצריא באינטרנט

פרויקט להקמת אתר סטטי לספריית אוצריא, שאפשר לארח בעלות נמוכה.

האתר יאפשר לחפש בספרייה ולפתוח כל מקור בכתובת קבועה. תוכן המקורות יהיה זמין ב־HTML שדפדפנים, מנועי חיפוש וסוכני AI יוכלו לקרוא גם בלי להריץ JavaScript. קישורים פנימיים ומפת אתר יסייעו בגילוי התוכן.

הפרויקט בשלב ההקמה.
