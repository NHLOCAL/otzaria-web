# אוצריא ברשת

האתר הסטטי של ספריית אוצריא: קריאה בעברית, חיפוש בטקסט המלא, כתובות קבועות למקורות וגישה מלאה למנועי חיפוש ולסוכני AI.

כל דף קריאה נוצר מראש כ־HTML. הטקסט, תוכן העניינים והניווט פועלים גם בלי JavaScript. החיפוש משתמש באינדקס Pagefind סטטי ומפוצל, והעדפות הקריאה נשמרות בדפדפן. אין שרת יישום, מסד נתונים מקוון או שירות חיפוש בתשלום.

## מקור הספרייה

היבוא מבוסס על **אותו מסד רשמי שהתוכנה עצמה מורידה**, מתוך [Otzaria/SeforimLibrary](https://github.com/Otzaria/SeforimLibrary/releases), ולא על איסוף עצמאי של כל הקבצים במאגרי המקור. מנגנון הבחירה משמר את בחירת הספרים, מבנה הקטגוריות, מזהי הספרים והשורות, המהדורות ופרטי המקור של אוצריא.

הסנכרון מאמת SHA-256 של חלקי הארכיון ושל הארכיון השלם, בודק את סכמת המסד ומשווה את מספר הספרים, השורות והקישורים לסטטיסטיקה הרשמית. קובצי התלמוד המצולמים מגיעים מחבילת ההשלמה הרשמית, בדיוק לפי ההבחנה בתוכנה בין הספרייה המובנית לקטלוגים חיצוניים. אין סינון ספרים לפי רישיון בפרויקט הרשמי הזה; פרטי הייחוס, המהדורות והודעות המוציאים לאור נשמרים.

גם קטלוג אוצר החכמה ו־HebrewBooks, שהמתקין מוריד מ־[Otzaria/otzar-HB_catalog](https://github.com/Otzaria/otzar-HB_catalog/releases), מיובא במלואו. ההפצה הזאת מכילה פרטי ספרים וקישורי מקור. הם מוצגים בקטלוג נפרד עם חיפוש לפי שם ומחבר, ועם קישורי קריאה מקומיים כאשר קיים מיפוי מפורש לספר שנכלל במסד הטקסט.

תיעוד הבחירה וההפניות המדויקות לקוד התוכנה: [מקורות וכללי שילוב](docs/UPSTREAM.md).

## מה האתר כולל

- קטלוג ספרים ותחומי לימוד, עמוד ספר ותוכן עניינים, קריאה רציפה ומעבר בין חלקים.
- כל טקסטי הספרייה הראשית, המהדורות הזמינות, ההערות וקישורי המקורות במסד הרשמי.
- כל רשומות הקטלוגים החיצוניים וכל מיפויי המקור, בעמודי HTML ו־JSON מדופדפים, עם חיפוש נפרד וקישורים מדויקים לספקים.
- איורי PNG ו־JPEG מתוך המקור, בקבצים סטטיים מאומתים, לצד קטלוג מלא של צילומי התלמוד. איור שחסר כבר במקור מסומן במפורש.
- עוגני פסקאות המבוססים על מזהי השורות של אוצריא, ולא על מספרי שורה שמשתנים בהוספת פסקה.
- חיפוש בעברית גם ללא ניקוד: כל המילים השלמות בשאילתה נדרשות באותו מסמך, ומירכאות מחפשות ביטוי רציף. סינון לפי תחום וטעינת תוצאות מדורגת. אין טענה לניתוח שורשים עבריים.
- תצוגה מותאמת לנייד, גופנים עבריים מקומיים, שינוי גודל אות, מצב כהה, סימניות והמשך קריאה.
- canonical נפרד לכל חלק, BreadcrumbList, Book ו־Chapter ב־JSON-LD, מפות אתר מפוצלות וקישורים רגילים שמאפשרים גילוי של כל הטקסט.
- `catalog.json`, קטלוג JSON מדופדף, `external/catalog.json`, `sources.json`, `llms.txt`, קובצי טקסט מלא ופרטי מקור לכל ספר, עם חותמות נפרדות למקור ולהורדה המעובדת.
- בדיקות תקינות מקור, בטיחות HTML, קישורים, כתובות, מכסות אחסון ובדיקות דפדפן ב־CI.

## הרצה מהירה לפיתוח

נדרשים Node.js 24 ו־Python 3.12 ומעלה.

```sh
npm ci
python3 -m pip install -r scripts/requirements.txt
npm test
npm run build
npm run verify
npm run serve
```

פתחו `http://localhost:4173/otzaria-web/index.html`.

הבנייה המקומית הראשונית משתמשת ב־`data/starter`: ספרים שלמים ומהדורות אמיתיות מהמסד הרשמי. זהו נתון פיתוח קטן, כדי שאפשר יהיה לתרום לפרויקט בלי להוריד כמה GB בכל התקנה. **פרופיל הפריסה הוא `full`, והוא אינו חוזר אוטומטית לאוסף הפיתוח אם המקור חסר.**

## בניית הספרייה המלאה

```sh
LIBRARY_PROFILE=full npm run sync
LIBRARY_PROFILE=full BASE_PATH=/ SITE_URL=https://your-domain.example DEPLOY_TARGET=cloudflare-r2 npm run build
LIBRARY_PROFILE=full BASE_PATH=/ SITE_URL=https://your-domain.example npm run verify
```

הורדת המקור, החילוץ, הטקסטים, דפי האתר ואינדקס החיפוש צורכים נפח דיסק משמעותי. יש לבדוק מקום פנוי לפני הבנייה המלאה. הטקסט מעובד ספר אחר ספר; אינדקסים גדולים נבנים בתהליכים נפרדים כדי לשחרר זיכרון בין מקטעים.

הפלט נמצא ב־`dist/`. כתובות הדפים מסתיימות ב־`.html`, ולכן אותו פלט מתאים גם לאחסון אובייקטים שאינו מבצע פתיחה אוטומטית של `index.html`.

אפשרויות שימושיות:

```sh
npm run sync -- --check
npm run sync -- --profile full --offline
BASE_PATH=/ DEPLOY_TARGET=cloudflare-pages npm run build
BASE_PATH=/otzaria-web/ DEPLOY_TARGET=github-pages npm run build
SEARCH_SHARDS=3 npm run build
# The standalone scheduler selects safe concurrency from CPU and available RAM.
SEARCH_CONCURRENCY=1 npm run build
# Compare the conservative default fragment grouping with one fragment per page.
SEARCH_FRAGMENT_TARGET_BYTES=0 npm run build
# Verify real archive boundaries, complete matrix coverage and cache invalidation.
BASE_PATH=/ node tests/partition-build.mjs
npm exec playwright install chromium
node tests/browser.mjs
```

## פריסה ועדכון אוטומטי

הבנייה המלאה מחולקת לשמונה עבודות `ubuntu-24.04` סטנדרטיות של GitHub. תמונת המקור מסונכרנת פעם אחת; כל עבודה מקבלת רק את קבוצת הספרים שלה, בונה את כל דפיהם ומאנדקסת את גוף הקריאה המצומצם. שלב האיחוד בודק hashes וכיסוי מדויק של כל הספרים והדפים. תוצר מתאים לפרסום רק אחרי בדיקת כל דפי ה־HTML ומבחני שאילתות על מנוע החיפוש שנבנה, בחיפוש כללי ובחיפוש לפי תחום.

יש מטמון לפי תוכן עם תקציב כולל של 9GB עשרוניים, המחולק לפי גודלי המקורות הדחוסים. כל עבודה שומרת חבילת תוצאה שלמה אם היא נכנסת להקצאה, או מטמון אינדקסים מוגבל כחלופה. אין שמירה כפולה חדשה של אותם אינדקסים בשתי השכבות. הקוד אינו דורש מכונת בנייה פרטית, runner בתשלום או שרת חיפוש. היעדר מטמון או אינדקס מטמון פגום גורמים לבנייה מחדש, ללא השמטת תוכן; ארכיון מחיצה שלמה פגום עוצר את האימות ומחייב הסרת הערך הפגום והרצה נוספת. [מחקר הביצועים](docs/PERFORMANCE_RESEARCH.md) מפרט את ההשוואות, המדידות והפשרות.

**היעד המומלץ למאגר המלא הוא Cloudflare R2 עם דומיין מותאם ו־CDN.** מגבלות מספר הקבצים של Pages חלות גם על דפי HTML, קובצי הורדה וקטעי אינדקס. בדיקת הגודל מונעת פריסה שחורגת ממכסות GitHub Pages או Cloudflare Pages; היא אינה משמיטה ספרים כדי לעמוד בהן.

תהליך GitHub Actions בודק עדכונים מדי יום בשעה 03:23 UTC, וניתן להפעילו גם ידנית. כאשר האתר המפורסם כבר כולל את אותה גרסת קוד ואותן חבילות מקור, הבדיקה המתוזמנת מדלגת על הבנייה הכבדה. יעד הפרסום נבדק לפני הורדה ובנייה: בהרצה ידנית אפשר לבחור `build-only` כדי למדוד ולאמת בלי לפרסם. שינויים ב־pipeline ב־PR מפעילים גם אימות מלא במטריצה, תמיד ללא פרסום. כישלון הורדה, חלק חסר או שגיאת אימות אינם מפעילים פרסום.

הוראות משתנים, הרשאות מצומצמות ל־R2, התאמת הדומיין, cache, גישה לבוטים ופריסה חלופית ב־Pages: [מדריך פריסה](docs/DEPLOYMENT.md).

באתר GitHub מסוג project, קובץ `robots.txt` תחת `/otzaria-web/` אינו קובץ robots של הדומיין כולו. דומיין ייעודי ב־Cloudflare מאפשר לפרסם אותו בשורש. `llms.txt` הוא ממשק גילוי נוח, ולא הבטחה לאינדוקס או לדירוג.

## מבנה הפרויקט

| נתיב | תפקיד |
| --- | --- |
| `config/sources.json` | המקורות הרשמיים, הסכמה הנתמכת ורשימת הפיתוח |
| `scripts/sync_library.py` | יבוא המסד הרשמי, מהדורות, הערות, מזהי שורות וקישורים |
| `scripts/sync_companions.py` | יבוא חבילת התלמוד המצולם ואימותה |
| `scripts/sync_external.py`, `scripts/sync_references.py` | יבוא קטלוגי הספקים והמיפויים לפי כללי התוכנה |
| `src/text.mjs` | פענוח טקסט, סינון תגיות פעילות וחלוקה לדפי קריאה |
| `src/ui.mjs`, `public/` | HTML סמנטי, עיצוב ושיפורים בדפדפן |
| `scripts/build.mjs` | יצירת האתר, היצוא למכונות ומפות האתר |
| `scripts/index-search.mjs` | בניית אינדקסי חיפוש סטטיים |
| `scripts/prepare-build-parts.mjs`, `scripts/package-build-part.mjs` | חלוקה והעברת קבוצות ספרים בארכיונים דחוסים |
| `src/search-*.mjs` | תכנון אינדקסים, קלט קומפקטי, מטמון, משאבים ושלמות |
| `scripts/profile-command.mjs` | מדידת זמן, זיכרון תהליכים ומשאבים בכל שלב |
| `src/external-build.mjs`, `scripts/index-external-search.mjs` | פרסום וחיפוש המטאדאטה של הקטלוגים החיצוניים |
| `scripts/check-size.mjs`, `scripts/verify.mjs` | בדיקות פריסה, SEO וקישורים |
| `scripts/deploy-r2.sh` | פרסום מדורג לאחסון ייעודי ואיסוף קבצים שהתיישנו |
| `.github/workflows/` | בדיקות, סנכרון ופרסום |
