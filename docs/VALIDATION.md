## מה נבדק בחיפוש המלא של המטאדאטה

`.cache/search-results/external-full-after-fix.json` עבר מול כל 223,835 הרשומות ו-45 האינדקסים שנוצרו בפועל. סכום `page_count` בקובצי הכניסה תאם למספר הרשומות. נבדקו שם ספר מדויק, שם רגיל, שם מחבר, סינון ספק, הכתובות המקוריות והעוגנים המקומיים.

בין הבדיקות: `בעין בוחנת` החזיר את רשומת אוצר החכמה 1; `מקראות גדולות - בראשית` כלל את רשומת HebrewBooks 14020 גם בשאילתה מצוטטת. הבדיקה האחרונה חשפה בתחילה פער של Pagefind סביב סימן פיסוק העומד כמילה בפני עצמו. לאחר התאמת תוכן החיפוש, התיקון נבדק מול האינדקס המלא; כותרת המקור והמטאדאטה נשמרו ללא שינוי. אין בכך טענה שכל צירוף אפשרי של סימני פיסוק נבדק.

זו הרצה של JavaScript ו-WebAssembly האמיתיים של Pagefind מתוך Node, עם קריאת קבצים המדמה `fetch`, ללא רשת וללא דפדפן. טעינת המטאדאטה הראשונית קראה 1,660,959 בתים ב-91 בקשות; כל סדרת הבדיקות קראה 6,472,323 בתים ב-476 בקשות. כל הבקשות נשארו בתוך אינדקס המטאדאטה החיצוני. זמני הריצה בדוח מודדים קלט/פלט מקומי ו-CPU, ואינם מדידת השהיה של CDN או ביצועים בטלפון.

[הרצת CI מספר 3](https://github.com/NHLOCAL/otzaria-web/actions/runs/44968862618) הסתיימה בהצלחה ב-22 בנובמבר 2026, בשעה 00:55:00 UTC, עבור הקומיט `1524b99ea257d465721c8ad73c5859c626b924d3`. נבדקו התקנה נקייה, בדיקות היחידה, בנייה ואימות תחת `/otzaria-web/`, בנייה ואימות תחת `/`, וחיפוש המאחד שלושה אינדקסים. מצב הריצה וכל שלבי ה-job אומתו גם דרך API של GitHub.

בדיקות הדפדפן ב-Chromium עברו 18 מתוך 18, ללא שגיאות JavaScript, אזהרות דפדפן או בקשות כושלות. הן כוללות קריאה ללא JavaScript, ניקוד וחיפוש, ביטויים מצוטטים, ניווט, סימניות, מצב כהה, גודל אותיות, נייד וקטלוגים חיצוניים. הצילומים ותיאור התוצאות נמצאים ב-[PREVIEW.md](PREVIEW.md); הדוח המפורט מצורף לריצה כארטיפקט `browser-evidence`.

**היקף ה-CI הוא ערכות הפיתוח.** `starter` כולל 18 ספרי בסיס שלמים ו-42 מהדורות חלופיות, ובסך הכול 60 יצואי ספרים. `starter-external` כולל 12 רשומות אמיתיות ו-44 מיפויי מקור, עם `complete: false`. בדיקות אלה אינן בדיקת דפדפן על 9,799 הספרים או על 223,835 הרשומות. בדיקת המטאדאטה המלאה שתוארה לעיל היא בדיקה נפרדת. לאחר CI מספר 3 עברו גם 45 בדיקות Node ו-41 בדיקות Python בריצה המקומית של התיקונים האחרונים. מצב ה-CI של שינויים מאוחרים יותר מופיע ב-[בדיקות ה-PR העדכניות](https://github.com/NHLOCAL/otzaria-web/pull/1/checks); התוצאות והצילומים ההיסטוריים המתוארים כאן נשארים משויכים להרצה מספר 3 ולקומיט שלה.

קובצי `.cache` ו-`dist-full` הם ראיות של הריצה המקומית ואינם נכללים בריפו. המדדים והחותמות החשובים נרשמו כאן כדי לשמר את תוצאות הבדיקה; בריצה חדשה יש להפיק דוחות חדשים מהפלט החדש. השלמת בנייה מקומית ובדיקות CI אינה אישור שהוגדרו דומיין, הרשאות אחסון, כללי מטמון או גישה של זחלנים דרך Cloudflare.
